# Security review

## Threat model

| Adversary | Capability | Mitigation |
|---|---|---|
| Relay operator | sees sealed bodies + headers | EHBP encryption; no plaintext in logs |
| Local machine snoop | reads session file | `0600`, opaque cookie only, no prompts |
| MITM on TLS | intercepts relay | TLS pinning by CA chain; enclave SAN pinning |
| Malicious enclave | publishes wrong key | attestation `*.hpke.*` SAN binding + host allow-list |
| Bot-gate provider | fingerprinting | challenge handled by relay, not spoofed locally |

## What is stored on disk

`~/.local/state/inspectorai-solana-chat/session.json`

```json
{
  "cookies": { "<relay cookie>": "<opaque value>" },
  "issued_at": 1764000000.0,
  "attestations": { "deepseek-v4-1-flash": { "hpke_public_key": "...", "domain": "...", "stored_at": 1764000000.0 } }
}
```

- **Never** stores: prompt text, reply text, API keys, the `x-is-human` token.
- Cookies older than 6 h are treated as dead before use.
- File mode `0600`; directory created 0700.

## Verification scope (be honest)

- **Done here:** DER parse of `enclaveCert`, SAN extraction, base32 decode,
  32-byte key length, `*.tinfoil.sh` host allow-list, `ehbp-v1` protocol
  check, HPKE suite pin, chunk digest + AEAD tag checks on responses.
- **Not done here:** Sigstore bundle verification, VCEK chain validation,
  measurement equality. Those live in the reference JS verifier
  (`@tinfoilsh/verifier` 1.4.0). The CLI exposes the raw bundle at
  `solana-chat attest --json` for a stricter verifier.

If your threat model treats the *relay* as hostile beyond "sees ciphertext",
the honest statement is: **transport is sealed, attestation binding is
structural, full attestation is upstream's**. Don't claim more than that.

## Hardening defaults

- Bridge binds `127.0.0.1` by default.
- `SOLANA_CHAT_API_KEY` enables Bearer auth; random key generated by the
  installer.
- systemd unit: `NoNewPrivileges`, `PrivateTmp`, `ProtectSystem=strict`,
  `ProtectHome`, `StateDirectory`.
- Non-root, no shell in the container.
